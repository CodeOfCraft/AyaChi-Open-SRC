# Ayachi

A modular Minecraft Bedrock Edition client built in C++20.

## Project layout

- `Ayachi/Client`: client lifecycle, managers, commands, and modules.
- `Ayachi/Renderer`: rendering backends and overlay helpers.
- `Ayachi/SDK`: Minecraft types and runtime interfaces.
- `Ayachi/Utils`: shared utilities.
- `Ayachi/Libs`: bundled third-party dependencies.

Open `Ayachi/Ayachi.vcxproj` in Visual Studio and build the `x64` configuration.
